### À propos

Je conçois et développe des produits web de A à Z : interface, back-end, base de données, déploiement et design. Mon projet principal est **Spider**, un bot Discord tout-en-un avec son dashboard, que je développe et maintiens seul.

- Je travaille surtout en **TypeScript**, du serveur à l'interface
- J'attache autant d'importance au design et à l'expérience qu'au code
- Je m'occupe aussi de l'hébergement et de la mise en production

### Projet phare : Spider

> Un seul bot pour remplacer tous les autres, réglable depuis un dashboard web.

| Domaine | Fonctionnalités |
|---|---|
| **Modération** | Automodération, sanctions progressives, validation par le staff, logs détaillés |
| **Protection** | Anti-raid, mode nuit, détection des liens d'arnaque, sauvegardes du serveur |
| **Communauté** | Niveaux et classements, concours, tickets, formulaires, alertes YouTube, Twitch et Kick |
| **Musique** | Lecture en vocal, lecteur web pour les membres, playlists partagées |
| **Plateforme** | Dashboard bilingue, documentation, blog, activité Discord intégrée |
